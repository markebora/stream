Version 1.2.0

Upload everything in this ZIP to your repo (markebora/stream), keeping the folders, and replace files when asked.
(Your bible/ folders, icons, server.js, update.json and installer.nsh are already in the repo: leave them.)

To ship a PROGRAM update (when main.js, preload.js, server.js, appupdate.js or package.json changed):
  GitHub > Releases > Draft a new release > Choose a tag > type v1.2.0 (a new number each time) > Publish release.
  The build runs by itself and attaches the installer. Installed apps download it and install when closed.

To ship an INTERFACE update (index.html only): replace index.html at the repo root. Nothing else.

Install the 1.2.0 installer by hand once: older installed copies have no program updater.
